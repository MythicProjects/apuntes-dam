# Desarrollo de Aplicaciones Multiplataforma

Apuntes del ciclo formativo de grado superior en Desarrollo de Aplicaciones Multiplataforma (DAM).

Cada curso sigue la misma estructura de carpetas:

- `00 Inbox`: notas pendientes de clasificar.
- `01 Asignaturas`: apuntes organizados por asignatura.
- `02 Recursos`: material de consulta transversal.
- `99 Adjuntos`: imágenes y otros ficheros enlazados desde las notas.
